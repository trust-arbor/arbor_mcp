inventory work. **Supported** means the stated library scope has an implementation;
it does not mean every clause in the wider source bundle has an exhaustive test.

This is a reviewed requirement inventory, not a certification. Links identify assertions configured in CI;
only the checkout-bound CI artifact records that they actually passed. Source inventories
marked partial or pending prevent a claim of complete specification coverage.

## Unadopted profiles

- **IDJAG.OPTIONAL**: When adopting actor delegation, rich authorization, multiple resources or sender-constrained grants, enforce their profile processing and proof-of-possession requirements; never treat a cnf claim as proof. Arbor does not implement DPoP, actor delegation or RAR policy. A host accepting these claims must validate them before access-token issuance; signature helper success does not authorize them.
- **APPS.FUTURE**: externalUrl/remote content formats, multiple UI resources per response, persistence/restore, custom sandbox policies, View-to-View and screenshot generation APIs are not adopted.

See [the coverage matrix](https://github.com/trust-arbor/arbor_mcp/blob/master/docs/MCP_COVERAGE_MATRIX.md#mcp-extensions) for unadopted MCP extensions.

Independent fixtures are identified separately from third-party implementation interoperability.
