# Migration guides

To move from ExMCP 1.x to the current Arbor packages, follow the
[v1-to-v2 migration guide](../guides/MIGRATING_V1_TO_V2.md). It covers packages,
public APIs, configuration, runtime ownership and rollback.

For the earlier ExMCP 1.0 dual-era protocol rollout, use the
[maintained 1.x migration guide](https://github.com/trust-arbor/arbor_mcp/blob/v1.6.0/docs/getting-started/MIGRATION.md).
Current protocol errors and compatibility settings are in the
[troubleshooting guide](../TROUBLESHOOTING.md) and
[protocol guide](../PROTOCOL_GUIDE.md).
