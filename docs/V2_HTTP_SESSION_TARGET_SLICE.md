# Retained legacy HTTP session target prerequisite

This private prerequisite does not activate `/sse` or `/message`. It adds a distinct installed-Gateway-established replay/IO target for those routes. The mounted `/mcp` GET path and modern listener contract are unchanged.

`HTTPWriterProxy.capture/2` captures potential session-target lifetime once at the original HTTP entry. It uses the root's configured owned/addressed session TTL (one hour by default), with a finite maximum of `0xFFFFFFFF` milliseconds. Missing sessions or an unsupported TTL cannot establish a target. The normal request cutoff remains unchanged.

The actual socket publishes its bounded endpoint setup descriptor into its already charged writer row before making an ID-only Gateway call. Gateway validates the socket, runtime, exact session lease and private server-derived transport endpoint, then establishes under the original short admission cutoff. `HTTPSessionStreamBinding.validate/2` exposes the immutable target cutoff, clamped to both the captured lifetime and the actual session expiry. Renewing a session does not renew this target.

Establishment and retirement of the prior stream for the same exact lease happen in one CAS transaction. Failure cannot claim a replacement occurred. The existing writer count and metadata bounds charge setup/target metadata; the existing IO count and byte bounds continue charging queued and entered writes. Retiring, expiring or replacing a target never kills a borrowed socket or releases entered IO before actual adapter return or writer DOWN. Cohort or installed Gateway/proxy replacement invalidates target authority without resetting outstanding physical credit.

The target cannot be reused as request, callback, initialization-claim or service-invocation authority. Its only planned consumer is retained replay/IO. Store reads must have separate finite RPC waits bounded by the immutable target deadline; each poll does not renew the target. Original source publication and durability authority remain short and retain their own phase/lease/cutoff proof.

All three supported verification toolchains pass 10 new pure-process lifecycle cases and 34 combined session-target/replay/modern-listener cases. Warnings-as-errors compilation, full formatting and strict Credo pass; normal and raw Dialyzer and ExDoc evidence are recorded separately in the immutable handoff. These cases cover original hour vs short request cutoff, exact registration/runtime/actor, endpoint mismatch, suspended Gateway expiry, queued successful caller reply expiry, generation replacement between entry and setup, charged setup pressure, atomic replacement with held IO, actual TTL expiry and cohort replacement. They do not run a network listener, native subprocess or repository test helper. Real alias handshake, durable-before-202 replay, terminal failure policy, resources, reverse helpers and public API retirement remain separate release gates.
