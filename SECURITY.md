# Security policy

Report suspected vulnerabilities in ExMCP 1.x or ArborMCP privately through
[GitHub's vulnerability reporting form](https://github.com/trust-arbor/arbor_mcp/security/advisories/new).
Do not disclose vulnerability details in public issues or pull requests.

Please include:

- The affected package version or source commit and relevant runtime/platform details.
- Reproduction steps or a minimal example.
- The potential impact and relevant configuration or logs, with secrets removed.

Use [GitHub issues](https://github.com/trust-arbor/arbor_mcp/issues) for other bugs
and feature requests. For deployment and configuration guidance, see the
[security guide](docs/SECURITY.md).
